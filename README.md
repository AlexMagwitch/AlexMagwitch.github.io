# Class1881

Этот репозиторий содержит исходный код небольшого статического сайта **Class1881**, написанного на чистом HTML, CSS и JavaScript и развёрнутого через GitHub Pages.

## Демо

Сайт доступен по адресу: https://alexmagwitch.github.io  

## Технологии

- HTML5
- CSS3
- JavaScript (vanilla)

## Структура проекта

- `index.html` — основная страница приложения  
- `css/` — стили оформления интерфейса  
- `js/` — клиентская логика  
- `images/` — изображения и иконки  
- `config.json` — базовые настройки проекта  
- `data.json` — основные данные, используемые на странице
